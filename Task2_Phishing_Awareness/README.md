# CodeAlpha Task 2: Phishing Awareness Training

## Overview

This project is a cybersecurity awareness training presentation focused on recognizing phishing attacks and avoiding social engineering threats.

## Topics Covered

* Recognizing suspicious emails
* Identifying fake websites and risky links
* Social engineering tactics
* Real-world phishing scenarios
* Security best practices
* Interactive quiz and answers
* Steps to take after clicking a suspicious link

## Presentation

The PowerPoint presentation for this task is included in this folder.

## Purpose

To educate users about phishing threats and encourage safer online behavior.
